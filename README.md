# 执行申请材料助手 · v1.0

在新版需求文档和五页面演示上实现的本地材料整理 MVP。适用于一个申请人、一个被执行人的限定场景，输出的是供人工核对的材料草稿，不是已审核的法院提交文件。

本仓库仅包含 v1.0 源码、依赖配置、测试、构建脚本及使用说明。需求文档、独立演示页面、设计图、参考资料、原始案件材料和本地导出文件不纳入版本管理；这些本地文件不会因此被删除。

## 使用入口

启动后的本机网页：[打开 v1.0](http://127.0.0.1:4173/)。此地址仅在本机服务运行时有效，不是公开网站。

下载或克隆仓库后，在仓库根目录运行：

    npm ci
    npm run dev -- --port 4173

需 Node.js 20.19 至 20.x，或 22.12 及以上；本次验证使用 Node.js 24.19.0。若本机 npm 默认缓存目录没有写入权限，可给 npm ci 指定一个可写的 --cache 目录。Windows 实机运行尚未验收。

可通过 npm run build:single 在本地生成单文件 HTML，内嵌页面、样式、文字解析及导出代码，无需额外下载前端资源；生成的独立页面不提交到本仓库。当前测试浏览器的安全策略禁止打开本地 HTML，因此尚未验证 file:// 双击运行；请优先使用已测试的本机网页入口，不能把单文件构建成功等同于离线兼容验收通过。

## 五步使用

1. **适用范围**：主动回答前四题；第五题默认“否”。第五题为“是”仍可继续整理材料，但不启用复杂项目自动计息。页面导航不会绕过导出检查。
2. **案件信息**：选择材料并点击“读取文字与候选”，或直接手填。候选列出文件名、页码或段落位置和原文片段，须逐项采纳。一审与二审的不同候选同时保留，不自动覆盖已有字段。另行填写拟申请执行法院，然后确认当前案件字段。
3. **金额试算**：选择“只整理本金”或“单本金固定年利率试算”，写明金额及口径依据，计算后确认。修改本金会同步案件页；任何相关修改都会使旧确认失效。
4. **文书与材料**：核对完整预览和附录，勾选材料清单并确认草稿性质后下载真实 DOCX 或 ZIP。清单勾选只记录用户操作，不证明材料有效或已经上传。
5. **官方填报**：逐项复制当前确认信息，再由本人进入人民法院在线服务网认证、上传和提交。工具不携带案件参数跳转，不代管账号、密码、验证码或 Cookie。

请在关闭或刷新前点击“保存本地草稿”，并确认下载文件确已保存。所有步骤均可保存草稿；应用没有自动保存到浏览器存储。

## 材料读取范围

每类最多 1 份，共一审文书、二审文书、身份证明或主体材料 3 类；每份最多 20 MB。

| 格式 | 本版行为 | 主要限制 |
| --- | --- | --- |
| 文本 PDF | 读取文本层，保留页码 | 最多 50 页、50 万字符；加密、损坏、超时或无足够文字时给出错误，不编造结果 |
| DOCX | 读取正文段落和表格中的文字，保留段落序号 | 正文 XML 最多 2 MB、5000 段、50 万字符；异常解压规模和修订文档拒绝解析；页眉、图片及其他部分不计入已解析正文 |
| UTF-8 TXT | 按非空行读取，保留原行号 | 最多 5000 个非空行、50 万字符；其他编码提示另存 |
| JPG / PNG、扫描 PDF、旧 DOC | 保留原件供用户自行查看，可按选择加入 ZIP | 不做 OCR；旧 DOC 请自行另存 DOCX 或文本 PDF |

候选规则只识别少量明确写出的法院、文书类型、案号、本金、执行角色标签和生效日期。不会把“原告/被告”自动当作申请执行人/被执行人，也不会从普通日期推定生效日期。复杂排版、图片、嵌入对象和不规范标签可能导致漏读或误读；原文件始终是核对依据。

材料读取失败不会覆盖手工填写的案件字段。身份证件号码不自动识别；人工填写的号码、地址等尚未输入时，会在草稿中标为“待补充”。

## 金额口径

本金是案件页、试算页、Word 和复制页共用的同一个字段。无默认演示本金、利率、日期或合计。

固定年利率试算：

    天数 = 截止日期 − 起算日期 + 1（日历日，包含首尾）
    利息 = 本金 × 年利率 ÷ 100 × 天数 ÷ 365
    合计 = 本金 + 最后一次四舍五入到分的利息

使用十进制整数和精确分数计算，避免浮点误差及夏令时少算一天。本金最多 12 位整数、2 位小数；利率在 0–100% 之间，最多 6 位小数；日期限定为真实的 1900–2100 年日期，区间最长约 100 年。

验算样例均为虚构数据：

| 本金 | 年利率 | 起止日期 | 含首尾天数 | 利息 | 合计 |
| ---: | ---: | --- | ---: | ---: | ---: |
| 100,000.00 | 3.45% | 2026-01-01 至 2026-06-30 | 181 | 1,710.82 | 101,710.82 |
| 125,000.00 | 4.2% | 2026-01-01 至 2026-06-30 | 181 | 2,603.42 | 127,603.42 |

这是一种须由用户核对依据的固定计算口径，不是对所有案件适用的法律计息规则。不自动处理部分履行、抵扣、分期、分段利率、多债权、责任比例、日期争议、法定迟延履行利息或其他费用。“只整理本金”不表示其他请求为零或已经放弃。

## 草稿与导出文件

- **DOCX**：可编辑的真实 Word 文件，包含当事人、执行依据、用户填写请求、独立的拟申请执行法院、签名位置，以及金额和人工核对附录。网页预览与 Word 使用同一份内容映射。
- **ZIP**：默认含 Word 草稿、本地 JSON 草稿、金额记录 JSON、材料清单 TXT、使用说明 TXT，共 5 份文件。只有明确勾选时才加入当前仍在页面内存中的原文件；恢复的文件名索引不会被伪装成原件。
- **JSON 草稿 v2**：保存案件字段、范围回答、计算输入、清单、核对记录、已采纳来源和文件索引；不保存原文件或全部解析文本。支持旧演示 v1 草稿迁移，缺项留空，不补演示值。
- **恢复校验**：导入前校验大小（最多 1 MB）、版本、结构、类型、长度、日期和数字；失败时保持现有内容。有效导入也需确认替换，旧合计及所有确认状态不被信任，金额按输入重算后要求重新确认。

输出门槛包括：适用范围、必要案件字段、案件字段确认、有效且已确认的当前计算结果、金额依据及最后的草稿确认。修改上游信息后，旧金额确认和导出确认会撤销。单纯切换到后续页面不能放行下载。

## 隐私与明确边界

文件读取和生成在本机浏览器内完成。应用无案件上传接口、遥测、云端 OCR、外部模型调用或自动提交功能；开发模式仅向本机开发服务器加载代码并连接更新通道。单文件产物还设有禁止网络连接的内容安全策略，官方入口只有用户主动点击时才打开。

原文件、解析文本和工作状态只保存在当前页面内存中；关闭或刷新后不会自动保留。下载的 JSON、Word、ZIP 都可能含明文敏感资料，应用不会加密它们，请自行妥善保存，勿公开分享。浏览器扩展、同步设置和系统本身的行为不由本工具控制。

五项执行条件核对是人工记录，不是自动法律审查。工具不作自动管辖、文书效力、主体真实性、法院受理或期限合规结论，不查询法院内部实时状态。

**模板未经法律专业审核，因此 v1.0 只提供显著标注的核对草稿，不提供“正式提交版”。** 草稿中保留的“待补充”、事实与理由提示、当事人其他要素及签名日期须在真正提交前按受理法院要求核对处理。

## 构建与验证

    npm test
    npm run build
    npm run build:single

生产目录为 dist/；单文件构建会另行生成上一级的「执行申请材料助手-v1.0-离线版.html」，不覆盖旧演示。

18 项自动测试覆盖公式与日期、精度和边界输入、上游确认失效、第五题分流、统一导出门槛、草稿迁移及伪造数据处理、候选来源、真实 UTF-8 TXT 读取、文件限制、法院独立映射、DOCX 结构和 ZIP 内容。浏览器验收使用虚构材料，已跑通 PDF/DOCX 读取、候选冲突与手工值保留、恢复草稿、复制、真实 Word/ZIP 下载，以及扫描件、加密和伪装 PDF 的错误路径。

最终源码生成的虚构 Word 样本为 3 页，已逐页检查中文、金额、法院映射和分页；早一轮浏览器实际下载的 Word/ZIP 也已完成内容与文件结构核对。二者分开记录：后续浏览器连接异常，未完成最终样式版本的重新下载。375×844 窄屏下五页正文均无横向溢出；材料选择按钮的竖排问题已修正，但该最后修正尚未完成浏览器复验。

兼容性证据限定为当前 macOS 的 Codex 内置浏览器和本机网页模式。Windows 实机、当地法院模板要求、生产部署及单文件双击运行尚未验收，不包含在“已通过”的范围中。

主要依赖锁定于 package-lock.json：PDF.js 6.3.289（Apache-2.0）、docx 9.7.1（MIT）、fflate 0.8.3（MIT）、React / React DOM 19.2.8（MIT）。许可证以对应已安装包的 LICENSE 为准；本次未加入收费 API 或服务。
